# Security and responsible disclosure

This repository contains an experimental firmware-modification workflow for a
single discontinued device configuration. It can render hardware unbootable.
It must not be used on systems without the owner's explicit authorization.

## Reporting a concern

For a security, safety, copyright, or provenance concern, use a private GitHub
security advisory if the repository owner has enabled it. Otherwise, open a
minimal public issue that does not include firmware dumps, personal data, or
additional exploit details.

## Scope

The project is intended for repair, interoperability research, and transparent
reproduction on the exact hardware/firmware combination documented here. It
does not contain vendor firmware or a generalized unlock for other products.
